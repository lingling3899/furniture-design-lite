# 家俬設計 Lite

靜態原型：上載房間相睇「原相 → 裝修建議示意」，或喺平面圖拖放傢俬擺位。

**預覽：** https://lingling3899.github.io/furniture-design-lite/?v=20261027a

## 功能

1. **相片建議**  
   上載房間相 → 揀風格（現代簡約／北歐／日式）→ 上半原相、下半（或並排）裝修示意。  
   MVP 用本地 Canvas 濾鏡＋傢俬標籤做示意（唔使登入、載入後可離線用）。真正 AI 實景圖需要後端／圖像 API，頁內有「請網頁工房／助手用 AI 出圖」說明。

2. **平面擺位**  
   拖沙發、餐桌、床、櫃、電視櫃到 2D 平面；位置存 `localStorage`；可重置／清空。雙撃圖示刪除。

3. **說明**  
   用法同免責。

## 免責

示意非實景、非報價；AI／風格建議僅供參考，唔作施工或專業設計圖。

## 技術

- 純 HTML／CSS／JS（無框架）
- GitHub Pages 部署
- Cache-bust：`?v=20261027a`

## 本地預覽

用任何靜態伺服器開 `index.html`，例如：

```bash
cd furniture-design-lite
python3 -m http.server 8765
# 瀏覽器開 http://127.0.0.1:8765/?v=20261027a
```
